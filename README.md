# nadir-observatorio.github.io

Sitio mínimo de Nadir, observatorio de riesgo y exposición. HTML y CSS estáticos, sin
JavaScript, sin rastreadores y sin solicitudes a otros dominios. Ninguna cifra está escrita en
estas páginas: las cifras viven en cada caso, junto a sus datos verificados.
