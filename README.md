# nadir-observatorio.github.io

Sitio de Nadir, observatorio de riesgo y exposición. HTML y CSS estáticos; un único script propio
y pequeño para el comparador de imágenes. Sin rastreadores, sin cookies y sin solicitudes a otros
dominios. Ninguna cifra se escribe a mano: el generador las lee de los datos publicados de cada caso y
comprueba su huella antes de usarlas.

- Tipografía: Jost, licencia SIL Open Font License 1.1 (`fonts/OFL.txt`), servida desde aquí.
- Imágenes de Viña del Mar: contienen datos modificados de Copernicus Sentinel (2024).
- Capacidad de respuesta (`casos/capacidad-respuesta/`): cada figura y cada capa llevan su licencia y su fuente en la página del caso.
- Daño a edificaciones (`casos/dano-edificaciones/`): figuras y datos con licencia CC BY 4.0 y las atribuciones de su página.
- Desiertos financieros (`img/desiertos-*.jpg` y su entrada de bitácora): capturas del mapa interactivo; contienen información de OpenStreetMap, disponible bajo ODbL.
- Código: licencia MIT.
